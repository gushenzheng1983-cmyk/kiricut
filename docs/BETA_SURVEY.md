# KiriCut 封闭测试问卷

> 给同行测试用。复制下面题目到 **腾讯问卷** 或 **Google 表单**，5 分钟可建好。

## 你怎么建（明天最快）

### 腾讯问卷（国内同行方便）

1. 打开 https://wj.qq.com/ 登录
2. 新建问卷 → 从空白创建
3. 把下面「题目全文」逐题复制进去
4. 发布 → 复制链接
5. 把链接填到项目里：`src/lib/betaFeedback.ts` 的 `BETA_SURVEY_URL`

### Google 表单（海外 / 日语用户）

1. 打开 https://forms.google.com
2. 空白表单 → 同样复制题目
3. 发布 → 复制链接 → 填入 `BETA_SURVEY_URL`
