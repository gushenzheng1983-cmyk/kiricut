## 推荐话术（跟测试者说）

> 白底商品图，先选平台，用 **AI 修图**。第一张用 **点我吸色校正** 点一下白底，再批量。红框盖全水印；有两处就修完一处 **换位置再点一次** 去水印。

## 测试用例

### 1. 基础 AI 修图（必测）

1. 上传角落水印样图
2. 选平台（如 Shopify / メルカリ）
3. 确认 **智能取色** 已开启
4. 点 **🎯 点我吸色校正** → 左侧原图点干净白底
5. 红框对准水印 → **AI 修图去水印**
6. 右侧结果：水印消失、无明显色块/框印

### 2. 双水印（今日修 bug，必测）

1. 上传 **两处水印** 的图
2. 红框对准水印 A → 去水印 → 确认 A 没了
3. 红框移到水印 B → **再点** 去水印
4. **预期**：A、B 都在；**不应**出现「修 B 时 A 回来」
5. 状态栏应出现：「在上次结果上继续修…」「还有水印？换位置再点…」

### 3. Mercari 斜框

1. 点 **メルカリ** 或 **斜角水印预设**
2. 左下角控制条可拖到空白处
3. 调角度/大小 → AI 修图

### 4. 换背景不复活水印

1. 去水印完成
2. 可选：去背景
3. 切换白底 / 透明 / 渐变色
4. **预期**：水印不应重新出现

### 5. 智能学习

1. 同平台连续处理 3～5 张
2. 侧栏「已从 N 张学习」数字增加
3. 状态从「刚开始学」→「学习中」

### 6. 快速覆盖（次选，白底小角标）

1. 模式改 **快速覆盖** + **纯色块**
2. 仅用于极小角标；商品图主流程仍用 AI 修图
